# Справочник по инженерии данных

В корне репозитория запусти `node server.mjs` (Node.js 18+) и открой [справочник](http://127.0.0.1:8765/). Оставь терминал открытым на время работы. Зависимости устанавливать не нужно.

Карточки хранятся в `cards.json`. Для обновления найди карточку по `id` и дополни её. Если тема встречается в двух разделах, добавь оба источника в `sources` этой карточки. Для PDF укажи название и страницу в названии источника.
